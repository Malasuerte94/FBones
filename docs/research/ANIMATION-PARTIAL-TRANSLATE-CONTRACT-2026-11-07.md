## Native fixture/test handoff

Native runtime authoring/sampling/remapping required no change after the audit.
The separate `scene_partial_translate_fixture.rs` retains the old mixed-family
fixture's X curves/raw−0 fields, ordered mode rows, complete Scale pair and seven
PNG resources, removes only its TranslateY timeline and gives the own source a
nonzero Setup Y17.25. The opt-in command is
`e2e_seed_partial_translate_fixture`, returning
`partial-translate-fixture/source.fbones`. Existing seed bytes/receipts are intact.

Five new owned native regressions cover absence/default sampling/model equality;
first-Y creation/last-Y deletion/recreation with fresh IDs, Undo/Redo and stale-ID/
last-X/partial-Scale negatives; mode identity/order through reparent/duplication
and mixed-family compatible/incompatible paste; actual Session sampling and three
portable Save/reopen phases without→with→without Y; and one atomic family batch.
The latter deliberately creates Y first in a candidate before an invalid X frame11
Bezier-neighbor insertion, requiring rejection without leaked Y/IDs/history, then
uses a valid frame21 linear interval for the positive one-history action.

The old native all-Y-deletion negative is replaced by last-X and incomplete-Scale
controls. Existing raw-bit/padding/nonfinite/curve/capacity protections stay.
New test/fixture syntax was parsed; coordinator compile/tests/integration remain
required. No schema, runtime solver, capacity, curve or inheritance code changed
in this native handoff, and no E/browser/original admission is claimed.
