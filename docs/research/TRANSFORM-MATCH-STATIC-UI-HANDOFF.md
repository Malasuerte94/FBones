Exact4.3.26 captures establish separate Offset-header and Properties-header
Match buttons, ordered Targets, independent source/target Local flags and six
source/destination rows. The endpoint cells use Min/Max placeholders where a
side is unmapped; mapped sides display ranges. Source X can connect to Rotate
and Y simultaneously. Global offsets and mapping endpoints are different data.
Both buttons were enabled with all mixes zero.

An offline recount of the existing independent snapshots gives:

| Accepted branch | Present cache cells before | After Offset Match | After Properties Match |
| --- | --- | --- | --- |
| Local/local | 0 | 0 | 24 |
| Reflected world/world | 0 | 0 | 24 |
| Reversed local target order | 0 | 0 | 24 |
| Sparse World-source / Local-target | 0 | 0 | 10 |

Each before branch has all 24 cells absent, even though mapped fields visibly
show numeric values: identity mappings display 0..1, while sparse source X
displays approximately 3.7..48.48 and ScaleY .6..-2.46. Thus null storage is not
a numeric zero and does not universally mean a blank display. The mixed after
state retains a reversed source ScaleY span. These are saved/visible facts,
not an observed manual endpoint-edit algorithm.

Properties Match fills only mapped sides in the sparse case, retains their
old spans and updates runtime mapping values together with the cache. Offset
Match leaves the cache untouched while changing all six global offsets, even
hidden ones. Both actions use the first ordered target in the observed local
branches. Do not materialize cache cells from display merely because an
inspector opens, or regenerate every runtime link from the saved cache on load.

The paired offline audit additionally verifies all21 routes across the four
existing Properties actions: runtime offsets/max agree with their stored cache
endpoints bit-for-bit, and each scale agrees with the float32 destination-span
divided by float32 source-span calculation. This strengthens the synchronization
invariant for those Match outputs. It still does not prove manual field-commit
rules, that the evaluator reads tag31, or a general world decomposition formula.
