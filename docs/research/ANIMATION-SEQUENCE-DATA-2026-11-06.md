Research-only tools may read pinned copies and emit ignored typed observations.

No product parser, codec, authoring model or UI changes belong to this initial

### Object123 setup — directly correlated

All216settings records match unique runtime slot+attachment+path targets:
193Region43 and23Mesh46. Region43/field15 and **Mesh46/field36** contain Object123;
Mesh46/field36's old zero-only Bool assumption was insufficient (zero was ambiguous
with a null object). All216observed settings are newly allocated domain records.
Their tagged field order is4,2,3,1, with the following unambiguous correlations:

| Tag | Corresponding runtime setting | Observed values |
| --- | --- | --- |
| 1 | start | 0,1,3,100 |
| 2 | count | 8,15,16,19,20,24,30,34,37,40,56 |
| 3 | digits | 1,2,3,5 |
| 4 | setupIndex | 0,4,13 |

**Every raw varuint is twice the corresponding nonnegative setting.** This is
consistent with signed ZigZag encoding and the editor's known integer serializers;
negative values were not observed. The earlier guess “raw32 means count32” was
wrong: in that observation it means count16; raw4 means digits2. Varied nonzero
start/setup values distinguish tags1and4 rather than relying on all-zero samples.
All4,826referenced PNG frame paths constructed from the supplied base path,
start+index and minimum digit padding exist in the provided conversion resources.
This is independent asset-inventory corroboration, not pixel/rendering evidence.

This establishes a bounded observed **data specification**, not an implemented
