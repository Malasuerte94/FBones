# macOS picker child metadata: pre-code DATA addendum

This narrows the child association required by the [picker DATA gate](NATIVE-MACOS-PICKER-CAPABILITY-DATA-GATE-2026-11-11.md); that gate remains unchanged. Use actual runner SDK declarations, not reconstructed layouts or a global process inventory. Apple's [libproc header](https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.h) declares proc_listchildpids; its [implementation](https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.c) scopes by parent and returns a PID count, unlike the byte-count convention of proc_pidinfo. Capture SDK/header/compiler pins on the actual hosted job. These public sources establish the interface, not successful child/AX observation on the target runner.

Permit bounded read-only enumeration of at most64 immediate children of the retained created main PID. Allocate one overflow sentinel and refuse truncation/overflow/ambiguous results; do not assume an empty or full buffer proves a complete stable snapshot. Revalidate main PID/start/image before and after. For each candidate require exact SDK PROC_PIDTBSDINFO byte count, live nonzombie status, same UID, ppid equal to the current main, fresh kernel start after this Save intent, proc_pidpath and stat file identity for the expected system osascript executable. Recheck the chosen child's PID/start/parent/file tuple immediately before every chooser action. Zero/multiple candidates or reparenting stops rather than broadening the search.

If actual argv is required, use only the SDK's scoped sysctl KERN_PROCARGS2 interface for this already-qualified own child, with a declared small bounded buffer and complete argc/NUL parsing. Apple's [sysctl header](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/sysctl.h) exposes this symbol as an unstable API: compile/availability/permission failure must remain a negative, not permission for private offsets or a global ps fallback. Compare only the exact source-derived executable/`-e` script/`--`/own default-name argv sequence. Persist bounded argv evidence only; never environment contents or unrelated command lines. Buffer overflow/truncation, missing terminators or excess argc refuses association.

This is metadata capability, not proof that osascript hosts the AX chooser. Independently require the real AX host/window/prompt associated with that exact current child and the fresh expected operation before input. A separate unproved dialog host stops the scenario. No OpenProcess-style global lookup, signals, attach, injected helper or desktop-wide System Events automation is introduced.
