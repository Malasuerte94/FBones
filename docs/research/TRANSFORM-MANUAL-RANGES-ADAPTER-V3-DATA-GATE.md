## Source-backed keyboard route, explicitly not installed-widget proof

Public LWJGL2-family source is pinned at commit
`2df01dd762e20ca0871edb75daf670ccacc89b60`, with private source hashes in
`keyboard-reference.json`. [WindowsDisplay](https://github.com/LWJGL/lwjgl/blob/2df01dd762e20ca0871edb75daf670ccacc89b60/src/java/org/lwjgl/opengl/WindowsDisplay.java#L813-L830)
dispatches characters separately from virtual-key events, decoding scan and
transition bits. [WindowsKeyboard](https://github.com/LWJGL/lwjgl/blob/2df01dd762e20ca0871edb75daf670ccacc89b60/src/java/org/lwjgl/opengl/WindowsKeyboard.java#L126-L155)
can enqueue a standalone character with keycode0, or associate it with a
retained key event. The native [message loop](https://github.com/LWJGL/lwjgl/blob/2df01dd762e20ca0871edb75daf670ccacc89b60/src/native/windows/org_lwjgl_opengl_Display.c#L119-L138)
calls TranslateMessage before dispatch; a posted Enter pair can therefore also
produce the normal character message. Do not add an automatic second Enter/
character13 to compensate without visible proof.

Current public [libgdx LWJGL input](https://github.com/libgdx/libgdx/blob/master/backends/gdx-backend-lwjgl/src/com/badlogic/gdx/backends/lwjgl/DefaultLwjglInput.java#L572-L601)
