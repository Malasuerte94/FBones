## New tool protocol and guard

Private V3 folder reuses fresh launch/ownership/capture/normal Save/close guards,
with a new actual-mouse module and driver. Approved=false and no final tooling
freeze until DATA and ROOT review. ROOT performs fresh launch and visual point
readbacks; coordinates/old PIDs are never inherited. All matching user-process
ledgers, including malformed ones failing closed, protect user82540 and older
windows. Source, prediction, package, launcher and actual backend DLL are pinned.

One unique navigation attempt injects an atomic absolute virtual-desktop
Move/LeftDown/LeftUp array only at an immediately verified visible/unoccluded
owned LWJGL point. This **is OS SendInput mouse injection**, intentionally allowing
ordinary focus to our fresh original; it is not hardware or background-only input.
It does not focus/restore a foreign window. No global keyboard, Alt, focus API,
thread attach, window uncover/reposition or repeated navigation fallback is used.
Fresh identity/rectangle/no-modal/held-button/modifier checks precede each click.

Only an actually visible inspector unlocks two ordinary actual field clicks,
80ms apart and revalidated between them. ROOT must then prove **full selection**
of existing text6, not merely a caret. Next, targeted own-child WM_CHAR10 only;
exact fresh draft10 unlocks one targeted scan-coded Enter; exact committed10
unlocks one normal Save. Every phase consumes its capture and has an exclusive
attempt receipt. Attempts/reporting distinguish submitted input from demonstrated
widget outcome and independently verified saved field changes.

Pointer restoration is conditional on both unchanged placed coordinates and
GetLastInputInfo matching our explicitly stamped injected event. New user input
suppresses restoration/next click; no attempt is made to restore another app's
focus. Partial Move+Down injection receives only a recorded safety Up, then stops.
A live desktop has unavoidable point-check/input race risk; the helper minimizes
it by immediate checks and serial input triples, not by claiming exclusive access.
