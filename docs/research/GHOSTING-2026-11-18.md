FBones provides an optional direct slot-owner filter and scoped Lock
and Refresh. A selection capture belongs to the logical document.
An intentionally empty selection uses all owners. A captured set
whose owners have been deleted remains a restricted scope. The
viewport computes full sampled clipping ranges before filtering image
paint. Bone ghosts retain their normal display scope.

Motion vectors use committed poses at the current frame and configured
earlier or later endpoints. They compare the same active Region or
Mesh attachment and vertex index in world units before presentation
offsets. The earlier lines run toward the current pose and the later
lines run from it. The threshold includes equal distances and excludes
zero-length marks. Vector geometry shares the scratch sample budget,
with a cap of 2,048 lines. Vectors can render alone, and they respect
the same direct owner filter. The endpoint choice, units, plain
strokes and budget are FBones policies.

FBones exposes one Ghosting sheet from Animate and Views. It uses the
editor's panel, line and accent tokens, with different colors for earlier and
later poses. The sheet can be dismissed while ghosting stays active. It owns
only session display state. Sampling uses the existing committed animation and
constraint solvers in scratch state. The viewport draws ghosts independently
of picking, gizmos, the current pose and the separate Preview canvas. Native
pose evaluation would replace the Session's geometry lease, so no ghost sample
calls it. Simulated Physics, extra attachment effects and motion vectors need
their own validation. Visible pending controls use explicit disabled states.

## Implemented FBones behavior

Frames and Key frames have independent Before and After switches, ranges,
steps, colors, and a Current switch. Current samples the committed clip while
the visible pose can carry working edits. Anchor aligns regular samples to
frame zero. Key step follows the ordered unique authored key times. The Loop
option uses the current timeline Repeat range. Offsets are world units per
relative frame. The closest samples have precedence up to 16, with the work
budget reduced for heavier rigs. Defaults and the range policies are FBones
choices.

Bones and tinted attachment images have independent switches and share the
opacity setting. Image ghosts use the supported pose, attachment activation,
deform, draw order and sequence samplers. Their render layers borrow the
viewport's document textures and use the existing region, mesh and clipping
paths. Ghost imagery uses a normal blend and a tint multiplied by the light
RGBA. Solid uses the sample color over the clipped attachment alpha.
Silhouette outlines the composed clipped alpha for each sample. X-ray
outlines each attachment's clipped alpha and composites those outlines
over the sample's fill. Bones and vectors operate separately. Simulate-on
Physics produces a status and suppresses ghost drawing.

## Verification

The production-CSP regression uses an owned Rust Session and a sprite moving
between authored frames 0, 4 and 8. At frame 4 it reads separated before/after
bone and image pixels, keeps the current Image and Preview pixels unchanged,
switches to key frames, plays, and returns to Setup. Dismissing the nonmodal
sheet with Escape restores focus to its launcher. The snapshot stays equal and
the test observes zero edit, save or native evaluation calls. Enabling image
ghosts adds no PNG requests for the loaded asset. The 960×720 panel stays
within the viewport and every numeric label fits after the layout correction.

Three focused cases and eight direct domain checks passed. The direct checks
exercise relative spacing, anchor, key stride, loop, limiting, Current priority,
pose sampling and source equality. The initial and final product REA receipts
retain trace identities and separate screenshot evidence. The final trace has
265 matched actions, 25 loopback responses with 2xx status and two Pixi image
conversion warnings. The original and product receipts are separate under
`.local/research/ghosting-2026-11-18/`.

All 133 production-CSP UI cases passed in two disjoint shards. JavaScript
passed 464 cases with one existing skip after the Pixi viewport test mock
was updated to represent child ordering. The final custom-protocol Linux
build reached WebGL and a visible owned window. The handed-over instance
exited later. Its launch receipt and binary are retained.
