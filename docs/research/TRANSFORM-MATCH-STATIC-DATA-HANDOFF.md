New sanitized report: `analysis/transform-match-static-check.json`, SHA256
`4c202af40fa529231d6b0eebc4729f26dcb456baa19702391f0c5d50d27c1414`.
It performs zero original commands. Its static package identity and all reused
source hashes are explicit. Six prior actions are mathematically inspected;
this is not six new editor actions or an eight-case rerun.

**Proven numeric relation, sampled21 routes:** for every destination of the
four accepted Properties actions, runtime fields and nullable tag31 satisfy
the following **bit-exact float32** relationships:

```text
From.offset == sourceStart
To.offset   == destinationStart
To.max      == destinationEnd
sourceSpan      = f32(sourceEnd - sourceStart)
destinationSpan = f32(destinationEnd - destinationStart)
To.scale    == f32(destinationSpan / sourceSpan)
```

This strengthens the older tolerance-based observation for these samples.
It does not prove a universal serialization invariant, that tag31 is read by
runtime evaluation, or how manual endpoint edits/clears must synchronize. In
particular, null endpoints cannot be fabricated from runtime fields without
losing demonstrated independent editor state.

The report also measures old spans implied by the first ordered destination
against new source-cache spans. They are close but not always equal: endpoint
quantization changes the span. Copying a previous scale instead of recomputing
from the actual endpoints would fail the accepted data, including the sparse
X-to-Rotate/Y case with formerly inconsistent scales.

## Candidate decomposition: supports inference, not exact code

Using independent double-precision matrices from authored bone channels, a
candidate world extraction uses matrix X-axis angle, signed determinant-X
scale, positive Y-axis magnitude and unwrapped relative axis shear. Local
observations use authored rotation/position/scales and shearY-minus90. World/
world Offset translation uses the source-world inverse applied to the target
origin; the sampled World-source/Local-target translation subtracts the source
world origin from target local channels.

This candidate fits the two accepted world/mixed Offset samples to maximum
absolute errors of approximately0.00049132 and0.00003555 respectively. Those
errors are **not bit-exact parity** and are not used to widen production
tolerances. A signed scale plus matrix angle is a numeric extraction candidate;
it is not proved to be a conventional transform decomposition that recomposes
the same matrix under every reflection.

The reflected Properties endpoints show quantization around five decimal
places, but addition order, f32 trigonometric approximation, significant digits,
negative rounding, large magnitudes and angle wrapping remain indistinguishable
from these samples. A generic decimal-round5 formula is not established.

## Documentation and remaining gate

The current official [Transform Match guide](https://en.esotericsoftware.com/spine-transform-constraints#Match)
was rechecked after the local evidence. It describes matching offsets to the
first constrained bone, but still presents one Local/Relative space and no
distinct Properties Match/range buffer. It does not settle the exact4.3.26
independent Source/Target spaces, reflected extraction or endpoint rounding.
Its version-unpinned description is documentation, not the missing code proof.

**Still unknown:** LocalSource=true/LocalTarget=false is absent from the accepted
set; no local-to-world formula is justified by symmetry. Angular branch/wrap,
singular/additive cases, nonzero mixes, which evaluated constraint stage Match
samples, and manual nullable endpoint editing/clear behavior remain unproved.

Next safe implementation can be the coordinated typed24-nullable-cell codec
and preservation integration described in `TRANSFORM-RANGES-CODEC-HANDOFF.md`.

preservation works. Match math remains a separate gate; do not implement the
missing direction by assumption or advertise complete exact editor parity.
New controlled discriminators may eventually address those gaps, but no new
original collection is performed or implicitly authorized by this memo.
