# Legacy metadata: preserve element identity across qualified label changes

Pre-code clarification for the new unconsumed Windowsv7 metadata-only route.
Do not modify the earlier [provider finding](NATIVE-TIMER-TEXT-AND-LEGACY-METADATA-DATA-GATE-2026-11-09.md),
which is already pinned by consumed Linux observations. No target/provider/
network/input operation by this DATA review.

Stock UpdateNotice.vue derives its button name from Updates and optional
progress/Ready child content. A captured0% label can become Ready while the
same button/root/runtime ID remains live. Literal equality to the caller's old
caption is therefore not required for this metadata-only query. This repeats
the already source-backed [closed label grammar](NATIVE-WINDOWS-MACOS-UPDATER-PROVIDER-V5-DATA-GATE-2026-11-09.md),
not a new native-name observation or arbitrary startsWith rule.

The SDK bridge must retain full exact runtime ID, own retained HWND/PID/start/
image, qualified provider owner/ancestry, visible enabled Button and root
association. It records bounded beforeName and currentName independently,
including null/length/truncation distinctions, and reads metadata only. The
controller's existing closed matcher must qualify **both** before/current full
names before the metadata facet can pass: Updates; Updates with integer0..100%;
or Updates with exact Version0.9.6 ready text, with the declared whitespace/
child-boundary rules. A transition between those forms is allowed for the same
identity. Unknown captions, roots, owners, truncated names or IDs fail the facet.

There is still no DoDefaultAction, Invoke, native click, replacement process,
keyboard or policy/security change in this scenario. Reading a DefaultAction
verb is metadata; a later actual action remains separately gated on a measured
own-capability. Preserve every consumed v5/v6/Linux gate/result unchanged.
