## Developer runtime

Install the downloaded archive in your game project:

```sh
npm install ./fbones-runtime-0.1.0-beta.1.tgz
```

The independent MIT package contains FBones code with no Spine runtime dependency.
Its headless Node/browser player needs neither the editor nor Pixi; `/pixi` adds
the optional PixiJS 8 view. The npm registry name is not published by this release.
Direct installation of the repository root installs the editor.

In the desktop app, **File → Export runtime** creates
`skeleton.fbones.runtime.json` and referenced PNG/WAV resources in a new folder.
The export preserves authored Setup/keys, rejects unsupported data and missing
resources, and does not mark the project saved. `.fbones` authoring files remain
binary. See the [runtime guide and examples](https://github.com/Malasuerte94/FBones/blob/v0.9.4-beta.6/packages/runtime/README.md).

## Source and verification

The release also includes the reviewed source archive, checksums and platform
build reports. Its source archive is for contributors; use the installer/package
above to get the app. All ten downloaded assets match GitHub digests and the nine payload/report
checksums. The four installers also match their exact source-commit build
reports. All three platform jobs and 114/114 hosted Ubuntu UI cases passed,
along with 16 runtime checks and 24 native-export samples.

This update makes desktop packages downloadable alongside the runtime and puts
direct links at the top of the README and release notes. It preserves beta5's
Animate drag/numeric/playback corrections, Sequence no-op/Undo fixes and native
File-menu fix. Beta5's verified source/runtime release and failed/withheld older
candidates retain their own evidence; none is relabeled as a beta6 test run.

The existing implementation checkpoint includes 114 passing Ubuntu UI cases,
418 JavaScript passes with one known skip, 16 runtime package checks and 24
native-export samples. Previous native/format and Windows interaction proofs
retain their named image/profile bounds. Package structure and architecture
checks do not establish native installation, hardware rendering, macOS GUI
acceptance or notarization. No new original Spine comparison is claimed.

Full Spine 4.3.26 project/runtime compatibility remains open. Runtime mixing,
direct binary-project loading, texture atlases, arbitrary skins/inheritance,
Path constraints and complete original numerical/Physics parity are not claimed.
Simulation remains bounded to 120 seconds. Unsupported documents stay guarded.
