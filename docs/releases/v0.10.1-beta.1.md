# FBones v0.10.1-beta.1

This beta focuses on working with existing Spine projects and exporting them
to a game. It includes signed updater packages for application version 0.10.1.

- **Spine game bundle** exports the skeleton JSON, texture atlas and PNG pages.
  The current mascot's edited bundle loaded and played in Dice Drop's Spine
  runtime with all 37 regions, 16 clips and eight direct Linked Meshes.
- **Animated GIF** exports a selected clip range, with output frame rate and
  loop controls. Chromium and Pillow confirmed the generated animation.
- **Editable Spine projects** now cover the verified direct Linked Mesh,
  Sequence, slot color and Path profiles. The tested mascot opened for editing,
  retained its linked meshes, and saved a copy that Spine 4.3.26 reopened.
  Inspection identifies unsupported structures and can repair a proven
  Linked Mesh chain into a separate editable copy.
- **Gravity** is available during Setup and Animate. The current workflow
  verifies signed scene-axis gravity, portable save/reopen and reproduction
  of the authored gravity and simulation step in the exported game data.
- **Path constraints** evaluate in Setup and Animate. Imported Position,
  Spacing and Mix keys appear in the timeline and can be retimed. Stock Spine
  accepted an edited save and Dice Drop verified the exported animation.

Compatibility is progressive. Path Deform, animated changes to the target
attachment of a Path constraint and other unsupported records can still
trigger Inspection mode. The [project checkpoint](../STATE.md) records the
verified cases and remaining limits. Linux and browser workflow checks cover
these scenarios. Platform installers are built and checked through the signed
release workflow.
