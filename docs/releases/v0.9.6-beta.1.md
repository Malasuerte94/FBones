## Transform Match fixes

Both **Offset Match** and **Properties Match** now sample the ordered scene with
the selected Transform constraint excluded. This fixes graphs where a later
Transform also affects the sampled source. Independent original Spine 4.3.26 actions
confirm all six Offset scalars and all 24 editor endpoints plus 24 runtime scalars
for the measured active Local/Local suffix graph. Authored bones, other
constraints, references and unrelated values remain preserved.

Match now gives a visible English/Romanian explanation when any Mix lane lies
outside 0–100%, including hidden lanes. Pending fields are committed before the
capability check. Extended authored Mix values remain editable and savable;
both Match buttons share the supported-range guard. One Match remains one
history action with Undo/Redo and binary Save/Close/Open coverage. Cached Physics
state and its clock remain separate from this scratch calculation.

A new active Local-source/World-target Offset observation supports the same
selected-excluded sampling class and first ordered target for that graph. It
retains the known World shear precision gap; this is no general World rounding
or bit-exact arithmetic claim. New independently encoded example projects pass
original Spine 4.3.26 loader/JSON export checks for their bounded profiles.

## Physics and Animate

Live Setup, explicit Simulate Off, preview holds, Reset, animated preview and
non-baking persistence retain regression coverage. A deterministic Play test
clock removes an edge caused by comparing slightly different f64/f32 key times;
no Physics solver, simulation clock or numerical tolerance changed.

Moving-parent/export Physics phase remains unresolved. General World/additive/
Physics Match sampling and arithmetic, manual range interactions and full
original numerical parity remain open. Existing Physics and both Match actions
stay the implementation priority while preserving Animate; skins are last.
Animated Physics preview remains bounded to 120 seconds. This bound does not
limit authored animation duration or default-live Setup continuation.

## Application updates and runtime

Version 0.9.6 is higher than the published updater-enabled 0.9.5 application.
Packaged clients use signed downloads and an explicit install/restart action;
pending fields and unsaved work retain Save/Discard/Cancel protection. Earlier
0.9.4 copies require a one-time updater-enabled installer. Portable workspace
copies cannot replace themselves. An actual installed 0.9.5 → 0.9.6 upgrade has not
been established by these local checks.

The independent MIT runtime stays at 0.1.0-beta.1 with no Spine runtime dependency.
Install the downloaded archive in a game project:

```sh
npm install ./fbones-runtime-0.1.0-beta.1.tgz
```

The editor's File → Export runtime creates a separate authored-data/resource
bundle; `.fbones` projects remain binary. npm registry publication, runtime
mixing and direct binary-project loading are outside this release.
