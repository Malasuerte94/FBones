# FBones v0.9.4-beta.2

First published source beta of FBones, a free, open-source offline 2D skeletal animation editor. The application version is 0.9.4.

This beta is **source-only**. No Windows, macOS, or Linux installer is attached.

The tag workflow gates publication on Linux x64, Windows x64, universal macOS,
and Ubuntu UI checks. Release JSON reports identify the source commit, package
hashes and structural checks. They do not establish native installation, GUI
startup, hardware rendering, or macOS notarization. Public installer downloads
remain a separate release milestone.

The earlier beta.1 tag remains an unpublished candidate: its gated UI run found
a test comparing poses from different Reset epochs. This candidate corrects the
test baseline and stabilizes a moving-pointer test target with a controlled browser
clock, while retaining the same 0.01 movement requirement, all 95 UI cases,
native-history/non-baking checks, and unchanged solver/editor behavior.

## Included

- Setup authoring: bones and affine transforms, hierarchy, PNG attachments and alternatives, meshes, binding/weights, clipping, color, blending, and draw order.
- IK, Transform, default-live Setup Physics, and shared Setup/Animate transform controls.
- Named animation clips and FPS; bone, slot, draw-order, deformation, constraint, and Event tracks.
- Dopesheet and Graph, editable Bezier curves, mixed key selection and clipboard, manual/Auto Key, playback/looping, and clean Preview.
- Animated Physics preview driven by timeline time, keyed coefficients and Reset, Simulate/Rebuild, and coherent mesh editing.
- Source, tests, contributor documentation, an implementation roadmap, and genuine FBones screenshots.

## Known limits

This is an early beta. Full Spine 4.3.26 project compatibility and game-runtime export are not delivered. Editing covers supported portable/default-skin structures; unsupported data stays inspection-only. Simulation preview is bounded to 120 seconds. Exact original Physics dynamics and broader Transform Match fidelity remain open. Path constraints, global Physics/reset-all, separate RGB/alpha/two-color tint, advanced timing, mixing, and onion skin remain pending.

Windows 0.9.4 was checked in WebView2 with GPU views, mesh interactions, and native Save As/Close/Open. Ubuntu browser tests use the actual Rust Session with the production CSP. Current packaged Linux lifecycle and macOS have not received equivalent release validation. Source availability does not imply a tested binary for each platform.

## Verification provenance

The existing 0.9.4 checkpoint records 95/95 Ubuntu UI cases, 263 passing JS tests with one known skip, 254 native and 93 legacy tests, and targeted Windows checks. Supported independent encoding has original 4.3.26 acceptance evidence; full compatibility does not follow from those samples. Public-release documentation and packaging do not add new original-editor observations. See [STATE](https://github.com/Malasuerte94/FBones/blob/v0.9.4-beta.2/docs/STATE.md) and [roadmap](https://github.com/Malasuerte94/FBones/blob/v0.9.4-beta.2/docs/ROADMAP.md).

## Install and contribute

Build instructions are in the [README](https://github.com/Malasuerte94/FBones/blob/v0.9.4-beta.2/README.md#getting-started). The application needs the usual platform Tauri prerequisites; Windows builds use WebView2. Source contributors can begin with [CONTRIBUTING](https://github.com/Malasuerte94/FBones/blob/v0.9.4-beta.2/CONTRIBUTING.md). No original editor installation is required for normal development or self-contained regression tests.

The release is intended to be marked **pre-release** on GitHub. Only artifacts explicitly attached to that release are downloadable deliverables; internal workspace launchers and reference-test tooling are not installers.
